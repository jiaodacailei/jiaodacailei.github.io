      会话

      商量行程

      今日きょうから1週間しゅうかん、よろしくお願いねがいします。

      从今天开始这一周，请多关照。

      「よろしくお願いします」——请多关照，正式场合或托付事务时常用的寒暄语。

      こちらこそ、お世話せわになります。スケジュール表ひょう、ありがとうございます。

      我才要请您多关照，谢谢您准备的日程表。

      滞在期間中たいざいきかんちゅうに、できるだけたくさんの取材しゅざいができるよう予定よていを立てたてました。ちょっとハード過ぎすぎますか。

      我安排了行程，想让您在逗留期间尽量多采访一些内容。会不会有点太紧了？

      「〜(よう)に」表目的，相当于中文的“为了……”；「〜すぎますか」用「動詞ます形+すぎる」表程度过头，委婉询问对方是否觉得过分。

      いいえ、とんでもありません。音楽おんがく、ファッション、映画えいが、食べ物たべもの、観光地かんこうち・・・。どれも関心かんしんのある所ところばかりです。

      不，哪里的话。音乐、时尚、电影、美食、观光胜地……每一项我都很感兴趣。

      「とんでもありません」是「とんでもない」的礼貌形，用来否定/谦让对方的说法，相当于中文的“哪里的话”。

      それから、水曜日すいようびだけは予定よていを入れいれていません。もしよかったら、その日ひ、有馬温泉ありまおんせんに寄っよってみませんか。

      另外，只有周三没有安排。方便的话，那天要不要去有马温泉看看？

      「〜ませんか」邀请对方一起做某事的委婉说法。

      温泉おんせんですか。

      温泉吗？

      ええ。1日にちくらいのんびりしたほうがいいと思っておもって…。

      嗯，我想您也该找一天放松一下……

      句末省略了后半部分（如“提案しました”），是日语口语中常见的“欲言又止”表达，留有余韵，不用补全说完。

      ありがとうございます。ぜひ行っていってみたいです。

      谢谢您，我很想去看看。

      分かわかりました。じゃあ、早速さっそく旅館りょかんを予約よやくします。

      好的，那我马上去预订旅馆。

      电话预订

      お電話でんわありがとうございます。「有馬ありま旅館りょかん」でございます。

      感谢您的来电，这里是“有马旅馆”。

      「でございます」是「です」的郑重语（丁重语），商务/服务场合自称时常用。

      すみません、予約よやくをお願いねがいしたいんですが…。

      不好意思，我想预订房间……

      「〜んですが」用来委婉引出请求/说明情况，后面常省略“よろしいでしょうか”之类的语句。

      はい、ありがとうございます。ご予定よていはいつになりますか。

      好的，谢谢惠顾。请问您预计什么时候入住？

      あさって、2名でめいで1泊はくなんですが、空いあいているでしょうか。

      后天，两位入住一晚，请问还有空房吗？

      「〜なんですが」委婉说明情况后，用「〜でしょうか」征询对方确认，比直接提问更客气。

      はい、20日はつかの水曜日すいようび、2名様めいさまで、ご1泊はくですね。少々しょうしょうお待ちまちくださいませ。

      好的，20号星期三，两位入住一晚，是吧？请您稍等。

      「お待ちくださいませ」是「待ってください」的最高礼貌形式，服务业接待客人时常用。

      はい、ご用意よういできます。1泊はく2食しょく付きつきで、お一人ひとり様さま16,000円えんになりますが、よろしいですか。

      好的，可以为您安排。一泊两食，每位16,000日元，请问可以吗？

      「〜になりますが、よろしいですか」是商务场合确认价格/条件后征询对方是否同意的固定说法。

      はい、結構けっこうです。

      好的，没问题。

      「結構です」在这里表示“可以，没问题”（肯定用法），要注意区分它也能表示委婉拒绝“不用了”，需靠语境/语调判断。

      かしこまりました。それでは、お名前なまえとお電話番号でんわばんごうをお願いねがいします。

      好的。那么，请告诉我您的姓名和电话号码……

      「かしこまりました」是「わかりました」的敬语（谦让语），服务业应答客人指示时的标准用语。

      课文

      第1段

      日本にっぽんには、全国ぜんこくに約やく3,000の温泉地おんせんちがあり、利用者りようしゃは1年間ねんかんに延べのべ1億おく4千万人せんまんにん以上いじょうといわれている。

      据说日本全国约有3000处温泉，一年的使用人次累计超过1亿4千万人以上。

      「〜といわれている」表示“据说……”，客观转述普遍看法/传闻，说明文常用表达。

      温泉おんせんといえば、地中ちちゅうから湧きわき出るでる温かいあたたかいお湯ゆのことだと思っておもっている人にんも多いおおい。

      说起温泉，很多人认为那是指从地下涌出的温热泉水。

      「〜といえば」表示“说起……”，引出话题的常见说法。

      しかし、冷たいつめたい水みずでも、規定きていの成分せいぶんを含んふくんでいれば温泉おんせんという。

      但实际上，即使是冷水，只要含有规定的成分，也可以称为温泉。

      「〜でも」表让步，“即使……也……”；「〜という」这里是解释性的“叫做……/称为……”。

      温泉おんせんの色いろは、透明とうめいなものから白くしろく濁っにごったものや青色あおいろをしたものまでさまざまである。

      温泉的颜色也是多种多样的，从透明的到浑浊发白的、乃至呈青色的都有。

      「〜から〜まで」表范围，“从……到……”。

      また、成分せいぶんの違いちがいによって、神経痛しんけいつうや皮膚病ひふびょう、高血圧こうけつあつなどいろいろな病気びょうきに効くきくといわれている。

      而且据说根据成分的不同，对神经痛、皮肤病、高血压等各种疾病都有疗效。

      「〜によって」表原因/依据，“根据……”。

      第2段

      かつて、温泉おんせんは病気びょうきやけがの治療ちりょうに使わつかわれていた。

      从前，温泉曾被用来治疗疾病和伤痛。

      「かつて」＝“从前，曾经”，常与过去时态搭配，书面语气较强。

      今いまは、環境かんきょうを変えかえてのんびりするために利用りようする人にんがほとんどだ。

      而现在，大多数人利用温泉是为了换个环境放松身心。

      温泉おんせんの多くおおくは自然しぜんの豊かゆたかな場所ばしょにある。

      大多数温泉都坐落在自然环境优美的地方。

      だから、緑みどりを見なみながら、露天風呂ろてんぶろに入っはいったり、広いひろいお風呂ふろでたっぷりのお湯ゆにつかったりすることによって、リラックスできるのだろう。

      因此，一边欣赏绿意一边泡露天温泉，或是在宽敞的浴池里充分泡个够，大概正是这样才能让人放松下来吧。

      「〜たり〜たりする」列举并列的动作；「ことによって」表示“通过……(的方式)”。

      第3段

      温泉地おんせんちでは、お客きゃくを集めあつめるための工夫くふうをしている。

      各温泉胜地都想方设法招揽游客。

      例えばたとえば、宿泊しゅくはくする人以外ひといがいがホテルや旅館りょかんの入浴にゅうよく施設しせつを有料ゆうりょうで使用でしようできる「日帰りひがえり温泉おんせん」がある。

      比如设有“当日往返温泉”，让非住宿客人也能付费使用酒店或旅馆的入浴设施。

      「〜以外が」＝“……以外的人”；「日帰り温泉」是专有说法，指不住宿只当天来泡温泉的服务。

      「入浴にゅうよく＋昼ひるご飯めし」や、「入浴にゅうよく+部屋へやでの休憩きゅうけい」など、宿泊しゅくはくする時間じかんのない人にんのためにさまざまなプランもある。

      还有“泡汤+午餐”“泡汤+客房休息”等各种套餐，专为没有时间住宿的客人准备。

      最近さいきんでは「日帰りひがえり入浴にゅうよく」専用せんようの施設しせつも増えふえてきている。

      最近，专门用于“当日往返泡汤”的设施也在不断增加。

      「〜てきている」表示某种趋势正在持续发展（“……起来了”）。

      第4段

      また銭湯せんとうといって、安いやすい値段ねだんで入浴にゅうよくできる施設しせつもある。

      此外还有一种叫做“钱汤”的设施，能以低廉的价格泡澡。

      「〜といって」＝“叫做……”，用来引出/解释一个名称。

      銭湯せんとうとは、多くおおくの家いえにお風呂ふろがなかったころに作らつくられた入浴にゅうよく施設しせつのことだ。

      所谓钱汤，是在很多人家里还没有浴室的年代建造的公共浴室设施。

      「〜とは、〜のことだ」是给名词下定义的固定句式，“所谓……，是指……”。

      現在げんざいではその数かずも少なくすくなくなってきているが、最近さいきんでは、「スーパー銭湯せんとう」が出てでてきて人気にんきを集めあつめている。

      如今这类设施数量已经减少，但最近出现的“超级钱汤”却很受欢迎。

      普通ふつうの銭湯せんとうより値段ねだんは高いたかいが、いろいろな種類しゅるいのお風呂ふろやマッサージ、エステなどがあり、1日中にっちゅう楽したのしめる。

      虽然价格比普通钱汤贵，但里面有各种各样的浴池，还有按摩、美容等项目，可以玩上一整天。

      「〜より」表比较基准，“比……”。

      「スーパー銭湯せんとう」は忙しいいそがしい人にんたちのちょっとしたいやしの場ばになっているのだ。

      “超级钱汤”已经成为忙碌人群的一个小小疗愈场所。
