      会话

      海报聊起，新作电影票房

      若者わかものの意識いしき

      年轻人的意识（课程标题）

      王おう

      あのポスター，張ちょう一心いっしんですね。

      王：那张海报上是张一心吧。

      担当者たんとうしゃ

      ええ。新作しんさく映画えいがの「朋友ほうゆう」が今週こんしゅう公開こうかいされたばかりです。

      负责人：是的。新作电影《朋友》这周才刚上映。

      「〜たばかりです」表示动作刚完成不久。

      興行成績こうぎょうせいせきは現在げんざいのところ第２だいに位いですが，来週らいしゅうはトップになる見込みみこみです。

      目前票房成绩是第2位，预计下周会成为第一。

      「〜見込みです」表示预计、估计会……。
      王おう

      張ちょう一心いっしんは中国ちゅうごくでは大だいスターですが，日本にっぽんでも，すごい人気にんきがあるんですね。

      王：张一心在中国是大明星，没想到在日本人气也这么高啊。

      担当者たんとうしゃ

      はい。彼かれが主演しゅえんする映画えいがは，アクションでも恋愛れんあいドラマでも，必ずかならず当たりあたります。

      负责人：是的。他主演的电影，无论是动作片还是爱情剧，一定会大卖。

      「アクションでも恋愛ドラマでも」（AでもBでも）表示无论A还是B；「当たる」在此意为（电影等）大获成功、卖座。

      中国电影的人气与其他国家

      王おう

      中国映画ちゅうごくえいがの人気にんきはどうなんですか。

      王：中国电影的人气怎么样呢？

      担当者たんとうしゃ

      ええ，この１か月げつで３本ほんの中国映画ちゅうごくえいがが公開こうかいされました。

      负责人：嗯，这一个月里上映了3部中国电影。

      どれも高くたかく評価ひょうかされています。

      每一部评价都很高。

      王おう

      中国以外ちゅうごくいがいではどこの国くにの映画えいがが人気にんきがあるんですか。

      王：除了中国以外，还有哪个国家的电影受欢迎呢？

      担当者たんとうしゃ

      アメリカや韓国かんこく…そうそう，日本映画にほんえいがの人気にんきも高またかまっていますよ。

      负责人：美国啊、韩国……对了，日本电影的人气也在提高哦。

      「そうそう」是想起某事时的插话，意为对了、是的是的；「高まる」是自动词，表示高涨、提高。
      王おう

      そうすると，外国がいこくのものだから人気にんきがあるというわけではないんですね。

      王：这么说来，并不是因为是外国的东西才受欢迎的呢。

      「そうすると」意为这样看来、这么说来；「〜というわけではない」表示部分否定，意为并不是说……。

      年轻人的喜好与口碑营销

      担当者たんとうしゃ

      ええ，若者わかものは日本にっぽんのものと外国がいこくのものを区別くべつしていないような気がきがします。

      负责人：嗯，我觉得年轻人好像并不区分日本的东西和外国的东西。

      「〜ような気がします」意为总觉得……、好像……，表主观推测。

      彼らかれらは，映画えいがにしても音楽おんがくにしても，いいものならすぐに受け入れうけいれます。

      他们无论是电影还是音乐，只要是好东西就会立刻接受。

      「映画にしても音楽にしても」（AにしてもBにしても）意为无论A还是B。
      王おう

      そうですね。中国ちゅうごくの若者わかものも同じおなじだという気がきがします。

      王：是啊。我觉得中国的年轻人也是一样的。

      じゃあ，彼らかれらの心こころをつかむには，どうすればいいんでしょうか。

      那么，要抓住他们的心，该怎么做才好呢？

      「〜には」在此表示为了……；「つかむ」意为抓住、掌握。
      担当者たんとうしゃ

      うーん…，難しいむずかしい質問しつもんですね。

      负责人：嗯……这个问题很难回答呢。

      やはり本当ほんとうにいいものを作るつくることではないでしょうか。

      果然还是要做出真正好的东西吧。

      「〜ではないでしょうか」是委婉地表达自己的看法，意为……不是吗、大概是……吧。
      王おう

      本当ほんとうにいいもの，ですか？

      王：真正好的东西，是吗？

      担当者たんとうしゃ

      ええ。今いまの若者わかものは，テレビＣＭより，同世代どうせだいの人ひとの口コミくちこみを信じしんじます。

      负责人：是的。现在的年轻人比起电视广告，更相信同龄人的口碑。

      「より」（AよりB）意为比起A更B。

      映像えいぞうでも音楽おんがくでも食べ物たべものでも，本当ほんとうにいいものを提供ていきょうすれば，口コミくちこみで広がひろがっていくはずです。

      无论是影像、音乐还是食物，只要提供真正好的东西，应该就会通过口碑传播开来。

      「〜はずです」表示按常理推断，意为应该会……。
      王おう

      なるほど。ありがとうございます。とても参考さんこうになりました。

      王：原来如此。谢谢您，这对我很有参考价值。

      课文

      第1段

      漫画まんがとアニメ

      漫画与动画（课文标题）

      日本にっぽんに来たきた外国人がいこくじんは，電車でんしゃなどでサラリーマンが夢中むちゅうになって漫画まんがを読んでよんでいる光景こうけいを見てみて驚くおどろくという。

      据说来到日本的外国人，看到上班族在电车等场合痴迷地读漫画的情景会感到吃惊。

      「〜という」在此表示传闻/转述，意为据说……。

      日本にっぽんの漫画まんがは，子供向けこどもむけから成人せいじん向けむけまで，対象たいしょうの年代ねんだいごとにさまざまな種類しゅるいがある。

      日本的漫画，从面向儿童到面向成人，按对象年龄层的不同有各种各样的种类。

      「〜向け」意为面向……、以……为对象。

      会社員かいしゃいんの生活せいかつや，経済けいざいに関すかんするものなど，大人おとなにしか楽したのしめない内容ないようの漫画まんがも多くおおくある。

      也有很多描写上班族生活、经济相关内容等只有大人才能享受的漫画。

      「にしか楽しめない」（〜にしか…ない）意为只有……才……，表限定。

      一方いっぽう，子供向けこどもむけの漫画まんがでも，大人おとなが楽したのしめるものも多いおおい。

      另一方面，即便是面向儿童的漫画，大人也能乐在其中的也不少。

      近年きんねん，中国ちゅうごくでは「クレヨンしんちゃん」「ドラえもん」「ちびまる子こちゃん」などの漫画まんがが子供こどもだけでなく大人おとなからも人気にんきを集めあつめている。

      近年来，在中国，《蜡笔小新》《哆啦A梦》《樱桃小丸子》等漫画不仅受到孩子们的喜爱，也深受大人的欢迎。

      第2段

      日本にっぽんのテレビアニメも外国がいこくでの評価ひょうかが高いたかい。

      日本的电视动画在国外的评价也很高。

      日本にっぽんで最初さいしょのテレビアニメは1963年ねんの「鉄腕てつわんアトム」だ。

      日本最早的电视动画是1963年的《铁臂阿童木》。

      漫画まんがをアニメ化しかしたものだが，その画質がしつは今いまとは比べくらべものにならないほど悪わるかった。

      它是把漫画动画化制作而成的，画质差到无法与现在相比。

      「〜ものにならないほど」意为……到无法相比的程度。

      その後ご，デジタル技術ぎじゅつの開発かいはつが進むすすむとともに，高画質こうがしつのいきいきとした映像えいぞうが生み出さうみだされるようになった。

      之后，随着数码技术的开发不断进步，画质高、生动的影像逐渐被制作出来。

      「〜とともに」意为随着……。

      「ドラえもん」「クレヨンしんちゃん」などの漫画まんがも，テレビ番組ばんぐみ用ようにアニメ化さかされ，高視聴率こうしちょうりつを獲得かくとくした。

      《哆啦A梦》《蜡笔小新》等漫画也被制作成电视动画节目，获得了很高的收视率。

      第3段

      やがて，最先端さいせんたんのデジタル技術ぎじゅつを使ったつかったアニメが映画館えいがかんのスクリーンに登場とうじょうし，娯楽性ごらくせいや芸術性げいじゅつせいの高いたかい作品さくひんが次々つぎつぎに制作せいさくされるようになった。

      不久后，运用最尖端数码技术制作的动画开始出现在电影院的银幕上，娱乐性和艺术性都很高的作品接连不断地被制作出来。

      第4段

      2001年ねんに公開こうかいされた「千せんと千尋ちひろの神隠しかみかくし」は，その豊かゆたかな想像力そうぞうりょくと高いたかい表現力ひょうげんりょくが世界的せかいてきにも高くたかく評価ひょうかされた。

      2001年上映的《千与千寻》，凭借其丰富的想象力和高超的表现力在世界范围内也获得了很高的评价。
