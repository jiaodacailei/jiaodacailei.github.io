# n2-exam-2020-12 操作日志

试点套：2020年12月N2真题的"言語知識(文字・語彙・文法)・読解"部分（問題1〜14，
共72题），电子化为模考页面。聴解部分不在这个页面里，复用已有的
`docs/private/n2-listening/2020-12/`，两个页面互相加了跳转链接。

## 素材来源

`C:\Users\leicai\Downloads\日本语能力考试N2.pdf等.zip` 里的
`2020年12月新日语能力试卷（N2）.pdf`（32页）。PDF文字层是自定义编码嵌入字体，
`pdftotext`/PyMuPDF文本提取都是乱码，只能视觉识读——5个并行agent分片读图识读
（问题1-47文字语汇文法、问题48-72読解+聴解选项、答案解析三段），加上我自己
补读了問題9/10共8题（agent因为指令写死"問題1~8"漏读了問題9/10，出现在p06-07，
落在part1的页码范围内但被指令误伤跳过）。

## 数据管道

1. 识读结果按题号合并（`merged_questions.json`），72题全部有题干+选项+正确
   答案+中文解析，无缺口。
2. 按大题类型规则把每题的"完整正确句"／选项拆成待配音文本清单（550条，
   `derive_items.py`）：
   - 問題1(文字読み)/2(漢字書き)/5(言い換え類義)：〈〉标记替换成正确答案
     文字。問題2的"あざやかな"这题〈〉跨度包含正确选项没有的活用尾巴"な"，
     手工加了 override（`ANGLE_FILL_TEXT_OVERRIDE`）。
   - 問題3/4/7(語彙/文法選択)：（　　）替换成正确答案文字。
   - 問題6(用法)：题干是裸词不填空，当作词条读；4个选项本身就是完整句子，
     各自配音。
   - 問題8(★排序)：手工核对5题的解析文字里"正确语序"，按真实顺序重组句子
     （`MONDAI8_ORDER`），不是自动解析。
   - 問題9(段落挖空)：4个空共享同一段文章，一次性全部填上正确答案拼成完整
     段落，只处理一次（不是4道题各自处理一次），再按句拆开配音。
   - 問題10〜14(読解)：文章按句拆分配音，问题句/选项各自配音。
3. `edge-tts`(ja-JP-NanamiNeural) 合成 + `faster_whisper`(medium) 逐词转写 +
   项目现成的 `align_group()` 打逐字符时间戳，跑了约90分钟（`batch_tts_align.py`，
   支持断点续跑）。550条里41条（多是"異色"这类2字短词）whisper对齐置信度
   不够、`align_group()`退回null，统一用现有代码同款的线性插值兜底补上
   （标了`char_times_fallback: true`）。
4. `build_exam_data.py` 用 `tools/listening/build_page.py` 的 `tokenize_ja()`
   对每条文本现场算假名注音+跟读时间戳，按"passage是不是'同上'"分组组装成
   `data.js`（`window.EXAM_DATA`），問題9/10-14的文章只在所属block渲染一次，
   不重复。

"听录音跟读"场景，这个是"限时作答→交卷判分→逐题复习"）：

  交卷后按"总对错数"+"每个問題的对错"判分（用户要求先做这个，不做JLPT官方
  量表分）、展开逐题解析。
- `docs/css/exam-page.css`（新）：题卡/选项按钮/正确错误配色。
- 复用 `docs/css/listening-page.css`（sticky-header/tab-bar底层样式）、
  `docs/js/private-gate.js`（密码门，跟全站共用同一个密码哈希）。

## 验证

- Chrome插件的 screenshot/javascript_exec/browser_batch 一直报错（先是权限弹窗
  超时，后来变成`clip.scale`参数反序列化错误），没能拿到真实浏览器截图。
  `get_page_text`（纯文本提取，不截图）是好的，用它对着真实localhost页面
  （不是jsdom模拟）核对过一遍全部72题的渲染文本，furigana/选项/解析都正确。
- 用 jsdom 搭了个无头测试（`scratchpad/jsdom_test/smoke.js`+`smoke2.js`）直接
  加载真实的 `index.html`+`data.js`+`exam-page.js`：渲染无报错、72题全部
  渲染、2145个`<ruby>`注音标签、模拟点选+交卷后判分逻辑正确（点对1题显示
  "1/72"、每個問題分别统计、未作答题目标红）、問題6裸词题干+完整句选项
  渲染正确、問題8重组句子furigana正确、問題9共享文章只渲染一次（18句，
  不是4×18）、問題11的3个passage分组/9道题分组正确。
- **用 `get_page_text` 核对全文时意外抓到一个真实bug**：問題10第(5)篇文章
  （q56）的passage字段开头混进了一句转写agent自己加的说明"（このページは
  前ページから続く文章の後半部分。冒頭が途中から始まっている）"，当成
  正文一起配了音——已定位到 `merged_questions.json` 把这句从passage字段里
  删掉，重新跑 `derive_items.py`（550条变548条）→ 增量重跑 `batch_tts_align.py`
  （断点续跑，只重新合成了3条新的passage句子）→ `build_exam_data.py` 重新
  组装，`get_page_text` 复核确认已经干净。全库搜索过其余71题没有同类污染
  （搜"続く/後半部分/前ページ/冒頭/このページ/途中から始"只有这1处命中）。
- **没有验证过的**：audio标签在真实浏览器里能不能正常播放（点击🔊/▶按钮
  之后有没有声音）——screenshot/click工具不可用，没法自动化验证播放行为，
  jsdom也不支持真实音频解码。文件本身非空、`<audio>`标签/data-audio属性
  接线正确，但**这一点需要用户实际点开页面听一下确认**。
