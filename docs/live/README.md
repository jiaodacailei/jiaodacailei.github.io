# 直播背景板（docs/live）

用法：大显示器放在身后，浏览器全屏打开某一场的页面（F11），人站中间，信息在左右两侧。

- `assets/live.css`、`assets/live.js`：所有场次共用，样式改这里。
- `_template/`：新场次模板（下划线开头，Jekyll 不发布）。
- `YYYY-MM-DD-slug/index.html`：每场一个目录，从模板复制后改标题、要点、下期预告；带 `todo` 类的是占位，替换后删掉该类。
- 键盘：`1-4` 切场景，`←/→` 上下一个，`H` 提示，`P` 自动轮播，`C` 显示光标。网址参数：`?scene=qa`、`?auto=40`。
- 新增场次后在 `index.html` 的列表里加一行。
