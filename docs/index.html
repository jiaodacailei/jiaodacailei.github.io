关于我

我是蔡磊，一名长期在日本 IT 行业工作的技术者。来日本已有三年多， 主要从事系统开发与技术工作，经历过从国内到海外的职场转型。

这个站点是我的个人空间，用来分享技术笔记、在日生活感悟， 以及一切觉得值得记录的事情。
