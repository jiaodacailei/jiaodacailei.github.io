派遣社员的薪资，为什么可能会有阶段性的、跳跃式的发展？而正社员，反而是不太容易涨薪资的。

那为什么呢？

先说结论：派遣的涨薪空间，就藏在派遣结构的每一层差价里。只要你有这方面的意识，薪资可以有比较大幅度的涨幅。

派遣结构：a → b → c

比如说，我的派遣结构是 a → b → c。你在c公司，假设——那c公司给你的钱，肯定很低嘛，对不对？

这个时候，如果说你能有通道，你自己脑袋灵光一点，你直接去找a公司谈。找b肯定不行，因为b是直接跟c联系的，所以你去找b是没意义的。你必须去找a。

你找到a之后，去跟他聊，他如果愿意要你，那这样的话，你就跨过了这个b，薪资可能会有一个大的提升。

每跨一层，至少多5万日元

一般来说，一个层级之间，至少是5万日元。就是说 a → b → c，也就是说a和c之间，会有10到20万的差价。

那么这个时候，你去跟a谈薪资的时候，你就很好谈嘛，对不对？你就很容易谈。

所以说，跳槽在派遣里面，是很容易涨薪资的。

我自己的账：派出价65万，我拿30万

我之前也是这么干的。我最早是22年到日本的时候，一个月30万日元。我进了现场三个月，就发现，他把我派出去的价格是多少——65万日元。差了35万。

我就找到社长，说：给我加薪资。然后那个社长就犹豫了一下。三个月给我加了5万，变成35万。

然后又过了一段时间，我就持续找他涨，我就说：继续涨。到了第二年的时候，就说给我加到40万日元的薪资，但是不能马上兑现，要隔个半年再给你涨上去。

在那个会社后来磨了将近两年左右。我觉得也对得起那个会社了——因为那个会社当时把我从中国办过来，人家也花了一定的资源，还有一定的功夫，你让人家赚点钱。

两年左右，我就跳了

两年左右我就跳了。跳的过程，就是我之前说的：当时是在一个项目中，另外一个会社作为上一级，我就直接去找上一级，我说：我能不能去你会社？他说可以。

我直接就谈薪资。当时我在这边是40万日元，然后我跟他谈，我说50万行不行？他说，50万ok。

我就50万日元过去了。
