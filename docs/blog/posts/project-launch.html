客户要3个画面，我交付了30个：一次零代码项目上线实录

蔡磊 在日IT技术者 · 零代码开发
2026-04-13 项目实录 零代码 日本大手

好久没更新了，最近一个日本大手客户的项目上线，有点忙。失踪人口回归！

这个项目的体制

除了会社安排了一个日语好的小伙伴对接客户需求之外，这个项目从设计、开发、测试到实施，就我一个人。全靠我这个单核CPU串行处理。

客户一开始说：「只要三个画面就好啦！」最后我交作业时：您的30多个画面，请签收。这是买一送十啊！

数据库：本来7张表，最后100多张

整个项目用零代码平台做底座，大部分画面点点配置就出来了，真需要敲代码的画面，一只手数得过来。

但数据库嘛，本来只想安静地建7张业务表，结果……

  • 定时任务→加个开源框架：附赠11张表
  • 流程要灵活配置→塞个工作流引擎：再抱走25张表
  • 业务想自由定制→搬出自家零代码平台：直接再添50张表
  • 权限和系统管理：顺手再来10张

最后到现场部署时，同行的小姑娘盯着数据库惊呼：「这表……有一百多？！」

零代码的优势，在现场救了我

现场实施时果然蹦出几个测试环境没逮住的「惊喜」，但这时零代码平台直接封神——改配置秒生效，不用重新发布！

还遇上大手客户的土耳其合作伙伴来参观，一堆人围着我们系统拍照合影，莫名有种产品出道的感觉……

验收通过，下个挑战来了

前几天客户终于验收通过，我们可以理直气壮喊打款啦！

暂时能喘口气，但接下来要挑战：让客户自己配置业务流程。现在技术其实已经实现，但得让客户摆弄 JSON 和 SQL……客户表示：我只是想拖拽一下而已啊！

下个目标：做出小白也能玩的拖拽式流程配置。项目虐我千百遍，我待开发如初恋。继续加油！
